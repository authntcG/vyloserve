# VyloServe Design System (`docs/design.md`)

> **File Utama:** Sumber kebenaran tunggal (*Single Source of Truth*) untuk desain dan mockup Google Stitch berada di [`design.md`](../design.md) pada root direktori proyek.

Dokumen tersebut memuat:
1. **YAML Front Matter**: Token desain terstruktur (warna, tipografi, border radius, bayangan, dan Material Symbols Outlined) yang dapat dibaca secara otomatis oleh mesin dan AI Google Stitch (`https://stitch.withgoogle.com/`).
2. **Aturan Warna & Theme Awareness**: Aturan penggunaan shade theme-aware vs statis, kontras, dan opacity modifiers.
3. **Pustaka Komponen Generik**: Potongan kode HTML5 + Tailwind CSS v4 siap pakai (*copy-paste ready*) untuk tombol, toggle, status badge, kartu modul, input formulir, modal dialog, dan tabel data proyek.
4. **Blueprint Prompt Stitch**: Kumpulan panduan prompt siap eksekusi untuk me-render Dashboard, Projects Hub, Apache, PHP, Database, Runtimes, dan Developer Terminal.
